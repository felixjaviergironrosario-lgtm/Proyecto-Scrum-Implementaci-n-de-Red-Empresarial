## **Proyecto Scrum: Implementación de Red Empresarial para DOÑA PANCH TECH ** 

**Descripción general del proyecto:** Este repositorio documenta el diseño, implementación y validación de una red empresarial segmentada bajo el marco de trabajo **Scrum** para la asignatura **Fundamentos de Enrutamiento (TI-202)** del el **Instituto Tecnológico de las Américas (ITLA)**. La misma fue construida e implementada en **Cisco Modeling Labs (CML)** utilizando nodos virtualizados Cisco IOSv/IOSvl2 y contenedores Linux todos compilados en el archivo .yaml del laboratorio.

Integrantes de la implementación: 

**Product Owner (PO):** Gerente de TI de DOÑA PANCH TECH (Onel Luis Pelegrino) **Scrum Master (SM):** Felix Javier Giron Rosario.
**Development Team (DevTeam):** Estudiantes / técnicos de redes (4–5).

    
- **Objetivos del Proyecto:**
    
    - Implementar y configurar una red jerárquica con múltiples switches y un router central (`R1`).
        
    - Configurar enlaces troncales (Trunks), encapsulación 802.1Q y agregación de enlaces (EtherChannel / Port-channel).
        
    - Establecer direccionamiento dual-stack (IPv4 e IPv6) y servicios DHCP con asignación dinámica.
        
    - Configurar protocolos de gestión de VLANs (VTP versión 3) y seguridad perimetral de acceso.
